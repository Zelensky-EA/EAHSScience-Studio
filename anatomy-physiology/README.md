# EAHS Anatomy & Physiology Learning Portal

47 investigations across 14 units, with student and teacher views.

For GitHub Pages: extract this course ZIP, upload its contents to your repository root, commit, and deploy from the branch / root. Keep index.html at the root. Students use index.html; teachers use teacher.html. The portable HTML is a local preview with inlined assets.

Predictions unlock the model. Record evidence at two distinct settings, describe a fair comparison, explain the result and complete the self-review. Feedback checks the starting prediction; writing is not automatically graded. Download HTML or JSON journals for your usual LMS submission.

Progress and presets stay in this browser/device; no accounts or shared dashboard are included. Export before changing devices or clearing browser data. JSON re-import is not implemented. Settings links include parameters, not journal text.

Teacher tools include larger models, numeric controls and sliders, grayscale, PNG/SVG, data CSV, print, shared settings and presets. Anatomical structures and illustrative curves state their limits; calculus uses radians. Read each model's assumptions.

AP unit organization and body-system organization were checked October 3, 2026. Reference: https://openstax.org/details/books/anatomy-and-physiology-2e

Numerical and DOM-fixture workflow checks passed. Full real-browser layout, download, printing, mobile and accessibility verification remains outstanding because the build environment has no browser binary. Preview after deployment before assigning the portal.
